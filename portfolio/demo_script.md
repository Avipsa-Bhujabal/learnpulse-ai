# Six-minute demonstration script

1. **Problem (30s):** define future recorded VLE inactivity and explicitly distinguish it from disengagement.
2. **Architecture (30s):** show CSV → DuckDB/Parquet → features → held-out evaluation → separate reference service.
3. **Data (40s):** explain daily aggregation, partition pruning and exact distinct resources.
4. **Personal baseline (40s):** contrast current seven-day behavior with earlier complete windows.
5. **Evidence (60s):** show unseen-course, calibration and uncertainty findings; avoid accuracy-only claims.
6. **API (45s):** score one synthetic row and emphasize the default null decision.
7. **Monitoring (35s):** show synthetic drift and delayed-label alignment.
8. **Workload (45s):** show aggregate capacity/backlog trade-offs without individual records.
9. **Limitations (35s):** discuss proxy outcome, course variation, calibration and non-causality.
10. **Next work (20s):** propose governed prospective shadow research, not deployment.
