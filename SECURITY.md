# Security policy

Version 1.0.0 is a local research prototype. It has no authentication or authorization guarantee and must not be exposed to a network without an independent security design. Report vulnerabilities using GitHub private vulnerability reporting if a public repository is created; until then, contact the repository maintainer through the agreed private project channel.

Do not include secrets or restricted learner data in reports. Model artifacts are hash-validated and readiness fails on corruption. Raw OULAD files and individual outputs must remain outside release packages.
