# LearnPulse 1.0.0 release notes

This local portfolio candidate packages the complete OULAD research workflow and a research-only reference scoring interface. The reference artifact is trained on all historical eligible data for software demonstration and creates no new held-out performance evidence. Earlier unseen-course experiments remain the scientific evidence.

Highlights include DuckDB/Parquet processing, within-person features, strict leakage boundaries, course generalization, nested calibration, explainability, subgroup and temporal audits, workload simulation, FastAPI inference, monitoring, CI and container definitions. Known gaps are the absent project license and unavailable local Docker runtime. No external publication occurred.
