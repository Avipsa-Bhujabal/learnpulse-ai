# LearnPulse portfolio case study

LearnPulse turns 10.7M OULAD activity records into partitioned Parquet daily summaries and leakage-safe behavioral windows. Personal baselines use earlier complete windows only; targets describe future recorded VLE inactivity, not motivation. Group-aware and unseen-course evaluation, nested calibration, transparent explanations, subgroup audits, temporal analysis and workload simulation expose both signal and failure modes. Step 17 adds a versioned research-only artifact, strict FastAPI inference, atomic batch scoring, drift monitoring, Docker and CI. The stack is Python, DuckDB, Parquet and scikit-learn. The system has not demonstrated causal impact or deployment readiness. A real next phase would require prospective shadow evaluation, governance, staff workflow research and safeguarding co-design with institutional partners.
